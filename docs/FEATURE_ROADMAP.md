## Feature 2: GitHub Comment Format (`--format github-comment`)

**Goal:** Replace ~60-line CI script blocks with single command output.

**Current state:** `--format markdown` exists but produces plain tables without GitHub-specific styling.

### Implementation

**File: `internal/cli/gauge.go`**

1. Add `"github-comment"` to format validation (line ~137)
2. Add `writeGitHubComment()` function (~50 lines)

**Output format:**
```markdown
## Confidence Report: {title}

| Metric | Value |
|--------|-------|
| Score | **{score}%** {emoji} |
| Threshold | {threshold}% |
| Status | {Passed/Failed} |
{delta row if baseline provided}

<details>
<summary>Factor Breakdown</summary>

| Factor | Score | Weight | Description |
|--------|-------|--------|-------------|
{factors...}

</details>

{sparkline image if history available}

---
<sub>Generated by confvis v{version}</sub>
```

**Emoji mapping:**
- Score >= threshold: :white_check_mark:
- Score < threshold: :x:
- Delta positive: :arrow_up:
- Delta negative: :arrow_down:
- Delta zero: :left_right_arrow:

## Feature 4: Config File Support (`.confvis.yaml`)

**Goal:** Eliminate repeated CLI flags across commands.

**Current state:** CLI flags only, no Viper dependency.

### Implementation

**Approach:** Add Viper for config file + flag merging. Precedence: config < env < flags.

**Config file locations (searched in order):**
1. `.confvis.yaml` (current directory)
2. `.confvis.yml`
3. `~/.config/confvis/config.yaml`

**File: `internal/cli/config.go` (new)**

```go
type Config struct {
    Gauge     GaugeConfig     `yaml:"gauge"`
    Generate  GenerateConfig  `yaml:"generate"`
    Aggregate AggregateConfig `yaml:"aggregate"`
    Fetch     FetchConfig     `yaml:"fetch"`
}

type GaugeConfig struct {
    Width       int    `yaml:"width"`
    Height      int    `yaml:"height"`
    Style       string `yaml:"style"`
    Dark        bool   `yaml:"dark"`
    FailUnder   int    `yaml:"fail_under"`
    BadgeType   string `yaml:"badge_type"`
    HistoryFile string `yaml:"history_file"`
}
// ... similar for other commands
```

**Sample `.confvis.yaml`:**
```yaml
gauge:
  width: 200
  height: 120
  style: github
  fail_under: 75
  badge_type: gauge
  history_file: .confvis-history.jsonl

fetch:
  timeout: 30

# Source-specific defaults
sources:
  codecov:
    service: github
  snyk:
    org: my-org-id
```

### Files to Modify

| File | Changes |
|------|---------|
| `go.mod` | +github.com/spf13/viper |
| `internal/cli/config.go` | New file: config loading |
| `internal/cli/root.go` | Init Viper, load config |
| `internal/cli/gauge.go` | Read from Viper with flag override |
| `internal/cli/fetch.go` | Read source defaults from config |
| `docs/cli-reference.md` | Document config file format |

### Verification

```bash

# Verify config is used
```

## Feature 5: Auto History Management

**Goal:** Simplify sparkline usage in CI - auto-persist history without manual file management.

**Current state:** Sparkline badge type works (`--badge-type sparkline`) but requires manual `--history-file` management.

## Feature 3: Baseline Storage/Comparison

**Goal:** `confvis baseline save` + `confvis gauge --compare-baseline` for easy regression detection.

**Current state:** `--compare <file>` exists but requires manual baseline file management.

### Implementation

**New `baseline` subcommand:**

```bash
# Save current score as baseline
confvis baseline save -c confidence.json [--ref refs/confvis/baseline] [--file baseline.json]

# Show current baseline
confvis baseline show [--ref refs/confvis/baseline]

# Compare against baseline (used internally by gauge)
confvis baseline compare -c confidence.json [--ref refs/confvis/baseline]
```

**Storage format (extends confidence.Report):**
```json
{
  "score": 85,
  "threshold": 75,
  "source": "aggregate",
  "savedAt": "2024-01-15T10:30:00Z",
  "commit": "abc123",
  "branch": "main",
  "factors": [...]
}
```

**New flags for `gauge` command:**
- `--compare-baseline` - Auto-fetch baseline from default ref and compare
- `--baseline-ref <ref>` - Custom baseline ref (default: `refs/confvis/baseline`)
- `--fail-on-regression` - (existing) now works with --compare-baseline

**File: `internal/cli/baseline.go` (new)**

```go
var baselineCmd = &cobra.Command{
    Use:   "baseline",
    Short: "Manage confidence baselines",
}

```

**File: `internal/baseline/baseline.go` (new)**

## Feature 6: Direct GitHub Check Creation


- `GITHUB_TOKEN` - Required, needs `checks:write` permission

## Feature 1: Native GitHub Action

**Goal:** `uses: boinger/confvis-action@v1` for zero-install usage.

**Current state:** Requires `go install` in workflows.

### Implementation

**New repository structure:**
```
confvis/
├── action.yaml              # Action definition
├── action/
│   └── entrypoint.sh       # Wrapper script
└── ... existing code
```

**Or separate repo:** `confvis-action/`

**File: `action.yaml`**

```yaml
name: 'confvis'
description: 'Generate confidence badges and reports'
branding:
  icon: 'check-circle'
  color: 'green'

inputs:
  config:
    description: 'Path to confidence.json or source config'
    required: true
  output:
    description: 'Output path for badge/report'
    required: true
  format:
    description: 'Output format (svg, json, markdown, github-comment)'
    default: 'svg'
  fail-under:
    description: 'Fail if score below threshold'
    default: '0'
  compare-baseline:
    description: 'Compare against stored baseline'
    default: 'false'
  create-check:
    description: 'Create GitHub Check with results'
    default: 'false'
  badge-type:
    description: 'Badge type (gauge, flat, sparkline)'
    default: 'gauge'
  deploy-badge:
    description: 'Deploy badge to gh-pages branch'
    default: 'false'

outputs:
  score:
    description: 'The confidence score'
  passed:
    description: 'Whether score met threshold'
  delta:
    description: 'Score change from baseline'

runs:
  using: 'composite'
  steps:
    - name: Setup confvis
      shell: bash
      run: |
        curl -sSL https://github.com/boinger/confvis/releases/latest/download/confvis_linux_amd64.tar.gz | tar xz
        sudo mv confvis /usr/local/bin/

    - name: Run confvis
      shell: bash
      run: |
        confvis gauge \
          -c "${{ inputs.config }}" \
          -o "${{ inputs.output }}" \
          --format "${{ inputs.format }}" \
          --fail-under "${{ inputs.fail-under }}" \
          ${{ inputs.compare-baseline == 'true' && '--compare-baseline' || '' }} \
          --badge-type "${{ inputs.badge-type }}"
```

**Usage example:**
```yaml
- uses: boinger/confvis-action@v1
  with:
    config: confidence.json
    output: badge.svg
    format: svg
    compare-baseline: true
    create-check: true
    deploy-badge: true
```
